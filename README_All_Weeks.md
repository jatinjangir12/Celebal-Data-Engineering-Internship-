## 📖 Overview

This repository contains all assignments completed during my **8-week Data Engineering Internship at Celebal Technologies**. The internship covered Python, SQL, Cloud, Apache Spark, Delta Lake, ETL pipelines, and end-to-end data engineering workflows.

| Week | Project | Key Topics |

| **Week 1** | Data Cleaning with Pandas | Data exploration, missing values, duplicates, filtering, cleaned dataset |
